# Placeholder Shooter — бета

Здесь лежат файлы открытого бета-теста **Placeholder Shooter** — тактического шутера 5×5 для телефона и ПК.
Код игры в этом репозитории не хранится, только готовые сборки.

- **Скачать:** раздел [Releases](../../releases/latest) — `Placeholder-Windows.zip` для Windows, `Placeholder.apk` для Android
- **Сайт и инструкция по установке:** https://sprivolk.github.io
- **Телеграм:** https://t.me/placeholder_shooter

Скачивай игру только отсюда, с сайта или из нашего Телеграма.
